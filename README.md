### Featured agentic projects

- [**Replicating an Asset Management Firm with Agents and Task Decomposition**](https://github.com/emitby/Replicating-an-Asset-Management-Firm-with-Agents-and-Task-Decomposition): five Claude agents replicate a firm's workflow, from data operations through quant research, performance analytics and investor relations to the investment team. They backtest a moving-average trend strategy and a five-lookback multi-asset momentum strategy (50/30/20 in the top three ETFs), compare both with SPY and QQQ, and produce a 29-page investor PDF. Code guardrails verify every number in it. Evals include 14 scorers, 42 red-team cases and live-trial pass rates.
- [**Agentic Prototype for an Encrypted Personal Assistant**](https://github.com/emitby/Agentic-Prototype-for-an-Encrypted-Personal-Assistant-That-Minimizes-the-Risk-of-Big-Data-Profiling): a coordinator delegates to security, travel and household agents. They check passwords against Have I Been Pwned using k-anonymity, search flights, and track groceries and supplies. Everything is stored in an AES-256-GCM vault, and secrets never reach the model.
- [**Multi-Agent Prototype**](https://github.com/emitby/Multi-Agent-Prototype): an OpenTable-style booking app for banquet halls. A concierge agent delegates to venue-scout and pricing agents. Agents can only place holds; confirming a booking takes a human.
